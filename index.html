Sanctuary Support

Moderation & Support System

Last updated: June 2026

Overview

Sanctuary Support is a modmail system used to manage structured communication between users and moderators.

Data We Collect

  • Discord User IDs
  • Discord usernames
  • Messages sent to the bot
  • Server roles and membership status
  • Ticket metadata (IDs, timestamps, status)

How We Use Data

Data is used only for moderation and support workflows.

We do not use data for ads, analytics, profiling, or AI training.

Data Storage

Stored securely for up to 30 days unless required for moderation cases.

User Rights

Users may request deletion via moderators or support tickets.

Security

Access is restricted to authorized moderation staff only.

Not affiliated with Discord Inc.
